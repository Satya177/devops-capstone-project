# User Stories

- **As a** Customer, **I want to** create an account **so that** I can access the system.
- **As a** Customer, **I want to** read my account details **so that** I can verify my info.
- **As an** Admin, **I want to** list all accounts **so that** I can manage users.
- **As a** Customer, **I want to** update my account **so that** my info stays current.
- **As a** Customer, **I want to** delete my account **so that** my data is removed.
